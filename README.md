# PLAYVID

PLAYVID is a Pan-African video platform built for Africa-first discovery, creator growth, and premium ad-free subscription experiences.

## Stack
- Frontend: Next.js + TypeScript + Tailwind CSS
- Backend: NestJS + PostgreSQL + Prisma
- Payments: Paystack
- Video hosting: Cloudinary
- Deployment: Vercel + Railway

## Features
- Long-form videos and shorts
- Recommendations and discovery feed
- Likes, comments, and followers
- Creator dashboard
- Ad-supported free tier
- Paid premium subscription no-ads experience
- Pan-African content identity and localized user experience

## Quick start

### 1. Install dependencies
npm install

### 2. Start the web app and API together
npm run dev

### 3. Environment variables
Copy `.env.example` and fill in the values for your services.

## Repositories
- Web app: `apps/web`
- API: `apps/api`

## Notes
This repository is intentionally scaffolded as an MVP foundation for PLAYVID and includes a ready-to-expand architecture for monetization, creator analytics, and premium subscription flows.
